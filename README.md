# Nature Sounds Player

Простое SPA-приложение на JavaScript с Webpack-сборкой. Позволяет проигрывать звуки природы с управлением громкостью и сменой фона.

---

## Стек

- JavaScript (Vanilla)
- Webpack (разделённый конфиг: `dev` и `prod`)
- Sass
- HTML
- ESLint
- Conventional Commits

---

## Функционал

-  Регулятор громкости
-  Три звука природы: зима, дождь, лето
-  Отключение предыдущего звука при запуске нового
-  Повторное нажатие — пауза / воспроизведение
-  Автоматическая смена фона страницы по типу звука
